# 🎤 Карафон (Karafon)

**Превратите ваш смартфон в портативное караоке!**

## 📖 Описание

Карафон — это мобильное приложение, которое позволяет петь под любую музыку, используя только смартфон и колонку. Включите музыку в любимом сервисе (VK, Яндекс.Музыка, Spotify, YouTube), подключите телефон к колонке и пойте!

## ✨ Основные возможности

- 🎤 **Передача звука с микрофона в реальном времени** (задержка < 100 мс)
- 🔊 **Раздельная регулировка громкости** микрофона и музыки
- 🎧 **Звуковые эффекты**: эхо, реверберация, автотюн
- 👥 **Режим дуэта** "Спой вместе" (подключение второго устройства)
- 🔌 **Поддержка всех устройств**: Bluetooth, AUX, AirPlay
- 💾 **Запись исполнения** с возможностью экспорта
- 🎨 **Современный минималистичный UI**

## 🚀 Технологический стек

### iOS
- **Язык**: Swift 5.9+
- **UI**: SwiftUI
- **Аудио**: AVAudioEngine, AVAudioSession
- **Минимальная версия**: iOS 13.0+

### Android
- **Язык**: Kotlin 1.9+
- **UI**: Jetpack Compose
- **Аудио**: AAudio, AudioRecord, AudioTrack
- **Минимальная версия**: Android 8.0+ (API 26)

## 📱 Платформы

- ✅ iOS 13.0+
- ✅ Android 8.0+ (API 26+)
- ✅ Поддержка Bluetooth 5.0+

```bash
# Или используйте Xcode для запуска
```

```bash

# Или откройте в Android Studio
```
