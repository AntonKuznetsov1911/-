# 🎤 Техническое задание: Карафон

## 1. 📖 Описание проекта

«Карафон» — это мобильное приложение, превращающее любой смартфон в портативное караоке.

Пользователь включает музыку любым удобным способом (VK, Яндекс.Музыка, Spotify, YouTube и т.д.), подключает телефон к колонке (Bluetooth, AUX, AirPlay), открывает приложение и начинает петь.

Голос через микрофон телефона передаётся на колонку вместе с музыкой — создаётся эффект караоке без специального оборудования.

## 2. 🎯 Цель

Создать максимально простое, интуитивно понятное и универсальное приложение для пения под любую музыку — в любом месте, на любом устройстве.

## 3. ⚙️ Функциональные требования

### Основные функции:

#### 🎤 Передача звука с микрофона в реальном времени

- Ввод звука с микрофона устройства
- Вывод звука через выбранное аудиоустройство (Bluetooth-колонка, AUX, динамик телефона)
- **Минимальная задержка (до 100 мс)**

#### 🔊 Регулировка громкости

- Отдельно для микрофона и фоновой музыки
- Возможность приглушить музыку и сделать голос громче

#### 🎧 Звуковые эффекты (опционально)

- Эхо / реверберация
- Автотюн (базовая настройка)
- Поддержка отключения эффектов

#### 👥 Режим "Спой вместе"

- Возможность подключить второй смартфон (через Wi-Fi Direct или Bluetooth)
- Оба устройства воспроизводят один и тот же трек
- Пользователи поют дуэтом

#### 🔌 Подключение устройств

- Определение активных Bluetooth-устройств
- Автоматическое подключение к последнему использованному устройству

#### 🎚️ Интерфейс управления

- Большая кнопка "Петь / Стоп"
- Ползунки громкости: микрофон / музыка
- Кнопка активации эффектов
- Индикатор уровня микрофона

#### 💾 (Опционально) Запись исполнения

- Возможность сохранить трек (видео или аудио)
- Экспорт записи и отправка в соцсети

## 4. 🎨 UI / UX

### Главный экран:

- Большая центральная кнопка 🎤 «Петь»
- Ползунок громкости микрофона
- Ползунок громкости музыки
- Иконка "настройки микрофона" (эхо / эффекты)
- Кнопка ⚙️ "Настройки"

### Настройки:

- Подключение устройства (Bluetooth / AUX)
- Выбор темы: светлая / тёмная
- Режим «Спой вместе»
- Включить/отключить эффекты

### Визуальный стиль:

- Современный минимализм (в духе Spotify / Apple Music)
- Мягкие градиенты, большие кнопки, понятные иконки
- Анимации при переходах и нажатиях

## 5. 🧩 Техническая архитектура

### Платформы:

- iOS (Swift + SwiftUI)
- Android (Kotlin + Jetpack Compose)
- Универсальный дизайн (адаптивный под планшеты)

### Основные модули:

#### Audio Engine

- Работа с системными аудиопотоками
- Буферизация и микширование микрофона с системным аудио
- Поддержка Bluetooth, AUX, встроенных динамиков

#### UI Layer

- Главный экран
- Экран настроек
- Экран эффектов

#### Audio Effects Engine

- Реализация эхо / реверберации / автотюна
- Настройки глубины эффекта

#### Device Manager

- Управление подключением Bluetooth
- Выбор устройства вывода

#### Networking (для "Спой вместе")

- Локальное подключение между устройствами (Wi-Fi Direct / Bluetooth)
- Синхронизация аудиопотока и состояния плеера

## 6. 🧠 Особенности реализации

### Критичные моменты:

- **Главная сложность** — минимизировать задержку звука
- Использовать нативные API для работы с аудио:
  - **Android**: AudioRecord, AudioTrack, AAudio
  - **iOS**: AVAudioEngine, AVAudioSession
- Эффекты реализовать через встроенные DSP (Digital Signal Processing)
- Оптимизация под слабые устройства:
  - Режим "низкое потребление"
  - Отключение эффектов

### Технические требования:

- Минимальная задержка звука: **< 100 мс**
- Частота дискретизации: **44.1 kHz** или **48 kHz**
- Битрейт: **16-bit** или **24-bit**
- Буфер: минимальный размер для конкретного устройства

## 7. 🌐 Совместимость

- Android 8.0+ (API 26+)
- iOS 13.0+
- Поддержка Bluetooth 5.0 и выше

## 8. 💰 Монетизация (по желанию)

- Бесплатное приложение с рекламой (баннеры внизу)
- Премиум-версия без рекламы + расширенные эффекты
- Встроенные покупки:
  - "Пакеты эффектов"
  - "Запись с улучшенным звуком"

## 9. 🧩 План разработки (MVP-версия)

### Этап 1 (1–2 недели)
- UI-дизайн и прототипирование

### Этап 2 (3–4 недели)
- Реализация микрофонного ввода и вывода на устройство

### Этап 3 (2 недели)
- Регулировка громкости и базовые эффекты

### Этап 4 (1 неделя)
- Тестирование на разных устройствах (Android/iOS)

### Этап 5 (опционально)
- Режим "Спой вместе"
- Запись исполнения

## 10. 🔒 Требования безопасности

- Запрос разрешений на микрофон при первом запуске
- Шифрование данных при передаче в режиме "Спой вместе"
- Локальное хранение настроек пользователя

## 11. 📊 Метрики успеха

- Задержка звука < 100 мс на 95% устройств
- Отсутствие крашей при переключении аудиоустройств
- Плавная работа на устройствах среднего уровня
- Время запуска приложения < 2 секунд
