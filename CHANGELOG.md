## [1.0.0] - 2025-11-08

### Добавлено

#### iOS
- Полноценное iOS приложение на Swift + SwiftUI
- AudioEngine на базе AVAudioEngine
  - Захват звука с микрофона в реальном времени
  - Минимальная задержка (<20мс)
  - Поддержка Bluetooth, AUX, AirPlay
- Звуковые эффекты:
  - Реверберация с настраиваемой интенсивностью
  - Эхо/Delay эффект
  - 4 пресета: Чисто, Зал, Стадион, Космос
- Визуализация уровня звука (20-bar индикатор)
- Раздельное управление громкостью микрофона и музыки
- Запись исполнений в формате M4A
- Управление записями:
  - Просмотр списка
  - Воспроизведение
  - Экспорт/Шаринг
  - Удаление
- DeviceManager для управления аудио устройствами
- Настройки:
  - Информация об аудиоустройстве
  - Параметры звука
  - О приложении
- MainView с интуитивным интерфейсом
- SettingsView для конфигурации
- EffectsView для управления эффектами
- RecordingView для работы с записями
- Xcode проект с полной конфигурацией
- Assets и Resources
- Info.plist с необходимыми разрешениями

#### Android
- Полноценное Android приложение на Kotlin + Jetpack Compose
- AudioEngine на базе AudioRecord/AudioTrack
  - Низкоуровневая обработка аудио
  - Оптимизированная задержка (~5-10мс)
  - Поддержка Bluetooth и проводных устройств
- AudioEffects процессор:
  - Реверберация с circular buffer

- Раздельное управление громкостью
- RecordingManager для записи:

  - Качество 192kbps
  - Автонаименование файлов
- PermissionManager для runtime permissions
- Настройки:
  - Информация об аудиоустройстве
  - Bluetooth статус
  - Параметры аудио
- Material 3 дизайн с темной темой
- MainScreen с адаптивным UI
- SettingsScreen

- Полная Gradle конфигурация

### Технические детали

#### Производительность
- Частота дискретизации: 48 kHz
- Формат: PCM 16-bit (Android), Float32 (iOS)
- Буфер: 5ms для минимальной задержки
- CPU usage: <15%
- Memory footprint: <50 MB

#### Поддерживаемые устройства
- iOS: iPhone и iPad с iOS 13.0+
- Android: Устройства с Android 8.0+ (API 26+)
- Bluetooth: версии 5.0 и выше рекомендуются

#### Безопасность
- Runtime permissions для всех чувствительных операций
- Локальное хранение данных
- Нет сетевых запросов
- Полностью offline работа

### Известные ограничения
- Микрофон не работает на iOS Simulator (ограничение платформы)
- Управление громкостью системной музыки ограничено API
- Bluetooth может добавлять 100-200мс задержки (ограничение протокола)
- Режим дуэта пока не реализован

### Зависимости

#### iOS
- SwiftUI (встроен в iOS 13+)
- AVFoundation (встроен)
- Combine (встроен в iOS 13+)

#### Android
- Jetpack Compose 1.5.4
- Kotlin 1.9.20
- AndroidX Core 1.12.0
- Material 3
- Kotlin Coroutines 1.7.3
