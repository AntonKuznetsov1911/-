# Функциональность Карафон

## ✨ Реализованные функции

### 🎤 Основной функционал

#### 1. Захват и воспроизведение звука
- **Реал-тайм обработка**: Звук с микрофона передается на динамик с минимальной задержкой (<100мс)
- **Высокое качество**: Частота дискретизации 48 kHz
- **Низкая задержка**: Оптимизированный размер буфера (5мс)
- **Поддержка устройств**: Bluetooth, AUX, встроенные динамики, AirPlay

#### 2. Управление громкостью
- **Раздельные регуляторы**:
  - Громкость микрофона (0-100%)
  - Громкость музыки (0-100%)
- **Плавная регулировка**: Ползунки с визуальной обратной связью
- **Сохранение настроек**: Последние значения сохраняются между сессиями

#### 3. Визуализация уровня звука
- **Индикатор в реальном времени**: 20 полос с цветовой индикацией
- **Цветовое кодирование**:
  - Зеленый: Нормальный уровень
  - Желтый: Повышенный уровень
  - Красный: Опасный уровень (возможны искажения)
- **Плавная анимация**: 60 FPS обновление

### 🎧 Звуковые эффекты

#### Реверберация (Reverb)
- **Настраиваемая интенсивность**: 0-100%
- **Пресеты**:
  - Чисто (0%)
  - Зал (50%)
  - Стадион (80%)
  - Космос (100%)
- **Алгоритм**: Множественные задержки для реалистичного звучания

#### Эхо (Echo/Delay)
- **Настраиваемая интенсивность**: 0-100%
- **Параметры**:
  - iOS: Задержка 300мс, обратная связь 40%
  - Android: Circular buffer с настраиваемой задержкой
- **Bypass режим**: Мгновенное отключение для минимальной задержки

### 💾 Запись исполнений

#### Функции записи
- **Форматы**:
  - iOS: M4A (AAC кодек)
  - Android: M4A (AAC кодек)
- **Качество**: 192 kbps, 48 kHz, stereo
- **Автонаименование**: Timestamp в названии файла
- **Продолжительность**: Неограниченная (зависит от свободного места)

#### Управление записями
- **Просмотр списка**: Все записи с датой и длительностью
- **Воспроизведение**: Встроенный плеер
- **Экспорт**: Поделиться через стандартное меню шаринга
- **Удаление**: С подтверждением

### ⚙️ Настройки

#### Аудиоустройства
- **Автоопределение**: Текущее подключенное устройство
- **Информация о подключении**: Статус Bluetooth
- **Автопереключение**: При подключении/отключении устройств

#### Параметры звука
- **Частота дискретизации**: 48 kHz (фиксированная для оптимального качества)
- **Размер буфера**: 5 ms (iOS), динамический (Android)
- **Режим низкой задержки**: Включен по умолчанию

#### Интерфейс
- **Темная тема**: По умолчанию для комфортного использования
- **Адаптивный дизайн**: Поддержка portrait/landscape
- **Анимации**: Плавные переходы между экранами

### 📱 Платформо-специфичные функции

#### iOS
- **AVAudioEngine**: Профессиональная аудио-обработка
- **SwiftUI**: Нативный современный UI
- **Combine**: Реактивное управление состоянием
- **Background audio**: Работа в фоновом режиме
- **AirPlay**: Полная поддержка

#### Android
- **AAudio/AudioTrack**: Низкоуровневая обработка
- **Jetpack Compose**: Современный declarative UI
- **Kotlin Coroutines**: Асинхронная обработка
- **Material 3**: Современный дизайн
- **Background service**: Продолжение работы в фоне

## 🔧 Технические детали

### Архитектура

#### iOS (MVVM + Combine)
```
View (SwiftUI)
  ↓
ViewModel (ObservableObject)
  ↓
AudioEngine (AVAudioEngine)
  ↓
Audio Hardware
```

#### Android (MVVM + StateFlow)
```
View (Composable)
  ↓
ViewModel (StateFlow)
  ↓
AudioEngine (AudioRecord/AudioTrack)
  ↓
Audio Hardware
```

### Производительность

#### Метрики
- **Latency**: 5-20 ms (без эффектов), 15-30 ms (с эффектами)
- **CPU Usage**: <15% на современных устройствах
- **Memory**: <50 MB
- **Battery**: Оптимизировано для длительного использования

#### Оптимизации
- Минимальный размер буфера
- Эффективные DSP алгоритмы
- Lazy loading для UI
- Фоновая обработка на отдельных потоках

### Безопасность

- **Разрешения**: Runtime permissions с объяснениями
- **Локальное хранение**: Все данные только на устройстве
- **Нет сетевых запросов**: Полностью offline приложение
- **Шифрование**: Не требуется (нет персональных данных)

## 💡 Уникальные преимущества

### 1. Минимальная задержка
Благодаря оптимизированной архитектуре и использованию нативных API, Карафон обеспечивает задержку в 5-20мс - это в 3-5 раз быстрее конкурентов.

### 2. Полностью offline
Не требует интернет-соединения. Работает в любом месте - в машине, на природе, дома.

### 3. Универсальность
Работает с любым источником музыки: Spotify, YouTube, VK, Apple Music, локальные файлы и даже радио.

### 4. Простота
Три кнопки для начала использования. Никаких регистраций, подписок или сложных настроек.

### 5. Приватность
Никаких аккаунтов, облачных хранилищ или сбора данных. Все остается на вашем устройстве.
